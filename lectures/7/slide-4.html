Оцінка в реальному часі (Real-time Scoring)

Fraud score для кожної транзакції

💰 Сума — незвично велика для цього клієнта?
📍 Локація — Київ → Нігерія за 1 годину? Неможлива подорож (impossible travel)
🕐 Час — 3:00 AM, нетиповий для клієнта?
📱 Пристрій (Device) — новий пристрій? Змінений fingerprint?
🏪 Торговець (Merchant) — категорія високого ризику? Нова країна?

Поведінковий аналіз

Профіль «нормальної» поведінки клієнта

1
Базовий профіль (Baseline)
Типові суми, merchant, час, локація
2
Моніторинг (Monitor)
Кожна транзакція порівнюється з профілем
3
Оцінка (Score)
Відхилення збільшує risk score
4
Дія (Action)
Low → OK, Mid → step-up, High → block

Adaptive auth: 200 грн у АТБ = OK. 50K переказ з нового пристрою о 3 AM = push-підтвердження або блок.

Грошові мули (Money Mules)
Ланцюжки переказів: A→B→C→D→зняття готівки
🎭
Синтетична ідентичність (Synthetic Identity)
Фіктивні особи з комбінації реальних та підроблених даних
📊
Виявлення патернів (Pattern Detection)
Кластеризація підозрілих транзакцій за спільними ознаками

Управління зворотними платежами

💳 Зворотний платіж (Chargeback) — клієнт оскаржує транзакцію → повернення коштів
💰 Вартість: сума + комісія $20-100 + репутаційний ризик
📊 Моніторинг: >1% рівень зворотних платежів = програма моніторингу від Visa/MC
🛡️ Захист: виявлення шахрайства + 3DS + зрозуміле ім'я торговця + політика повернення

ML-модель: ключові ознаки

Конструювання ознак (Feature engineering) для виявлення шахрайства

💰
Транзакційні ознаки
Сума, валюта, MCC-код, тип операції (CNP/CP), час доби, день тижня
👤
Профільні ознаки
Середня сума за 7/30 днів, частота, улюблені merchant, звичний час операцій
📱
Пристрій та мережа (Device & Network)
Device fingerprint, IP геолокація, VPN/proxy detection, browser language
⚡
Ознаки швидкості (Velocity)
Кількість транзакцій за 1/5/60 хв, кількість різних торговців, швидкість неможливої подорожі

Типова ML-модель для виявлення шахрайства: 200-500 ознак. XGBoost/LightGBM для швидкості, нейронні мережі для складних патернів.

Оцінка в реальному часі (Real-time Scoring) — архітектура

Обробка мільйонів транзакцій на секунду

1
Прийом транзакцій
Kafka/Kinesis приймає потік транзакцій. Збагачення даними: GeoIP, device, history
2
Сховище ознак
Redis/Aerospike зберігає попередньо обчислені ознаки клієнта. Оновлення в реальному часі
3
ML-висновок (Inference)
Модель повертає оцінку шахрайства 0-1000 за <10ms. GPU/FPGA для прискорення
4
Механізм правил
Пост-ML правила: санкційні списки, обмеження швидкості, чорний список торговців
5
Рішення та дія
Схвалити / Додаткова перевірка (OTP) / Відхилити / Черга на перевірку. SLA: <100ms наскрізно

Зворотні платежі (Chargeback) — потік

Від диспуту до вирішення

1
Диспут клієнта
Клієнт повідомляє банк-емітент: "Не визнаю транзакцію" (fraud / товар не отриманий)
2
Перший чарджбек (First Chargeback)
Емітент повертає кошти клієнту, стягує з еквайєра. Код причини (Visa: 10.4, MC: 4837)
3
Повторне подання
Торговець оскаржує: надає докази (підтвердження 3DS, підтвердження доставки, збіг AVS)
4
Арбітраж (Arbitration)
Якщо не вирішено — арбітраж Visa/MC. Штраф $500+ програвшій стороні

Chargeback rate >1% = Visa VDMP / MC ECM програма моніторингу. >1.8% = штрафи до $100K/міс та загроза відключення.

Поведінкова аналітика

Поведінкова біометрія та профілювання користувача

⌨️ Динаміка натискань клавіш (Keystroke dynamics) — швидкість набору, час між натисканнями, паузи. Унікальний "почерк" друку
📱 Патерни дотику (Touch patterns) — тиск, площа дотику, кут нахилу телефону, свайп-патерни
🖱️ Динаміка миші (Mouse dynamics) — швидкість руху, криві переміщення, патерни кліків. Бот vs людина
🕐 Поведінка сесії (Session behavior) — порядок дій, час на сторінці, навігаційні патерни. Шахрай діє інакше
📊 Безперервна автентифікація (Continuous auth) — перевірка протягом всієї сесії, не лише при вході. Оцінка ризику оновлюється

BioCatch, BehavioSec — лідери ринку. Виявляють троянів віддаленого доступу (RAT), соціальну інженерію та перехоплення сесій.

🛡️

Ключові висновки

1️⃣ ML + Rules — гібридний підхід для fraud detection
2️⃣ Оцінка в реальному часі (Real-time scoring) — рішення за <100ms для кожної транзакції
3️⃣ Поведінкова аналітика — профіль клієнта = базова лінія для виявлення аномалій
4️⃣ Графова аналітика — виявлення мереж шахрайства та ланцюжків грошових мулів
