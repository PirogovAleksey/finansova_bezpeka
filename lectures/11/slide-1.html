Лекція 11.1

Розміщення, розшарування, інтеграція, типові схеми

Відмивання коштів фінансує організовану злочинність, тероризм, корупцію та наркоторгівлю.

Три етапи

1
Розміщення (Placement)
Готівка → фінансова система. Структурування (Smurfing), бізнеси з готівкою, казино
2
Розшарування (Layering)
Серія переказів для маскування. Компанії-оболонки (Shell Companies), офшори, крипто
3
Інтеграція (Integration)
«Чисті» кошти → легальна економіка. Нерухомість, бізнес, розкіш

Сучасні схеми

🚢
Через торгівлю (Trade-Based ML)
Товар за $10K оформлений за $100K. Різниця відмивається
🪙
Крипто-відмивання (Crypto ML)
Міксери, стрибки між ланцюжками, монети конфіденційності, P2P
🧑
Грошові мули (Money Mules)
Рекрутування людей через фейкові вакансії для переказів
🏢
Компанії-оболонки (Shell Companies)
Фіктивні компанії в офшорних юрисдикціях для розшарування

Структурування (Smurfing)

Дроблення для обходу порогів

💰 Поріг: 400,000 грн в Україні, $10,000 у США
✂️ Smurfing: 10 внесків по 39,000 грн замість одного 390,000 грн
🔍 Виявлення: моніторинг транзакцій бачить патерн дроблення
⚖️ Структурування — саме по собі є злочином, навіть якщо кошти легальні

Відмивання через торгівлю (Trade-Based ML)

Маніпуляції в міжнародній торгівлі

📈
Завищення вартості (Over-Invoicing)
Товар вартістю $10K продається за $100K. Різниця — відмиті кошти
📉
Заниження вартості (Under-Invoicing)
Імпорт за заниженою ціною, різниця оплачується «тіньовим» каналом
📦
Фіктивні поставки (Phantom Shipments)
Оплата за товар, який ніколи не відвантажувався
🔄
Множинне інвойсування (Multiple Invoicing)
Одна партія товару оформлюється кількома інвойсами для збільшення обсягу

TBML складає до 80% незаконних фінансових потоків — найбільший канал відмивання у світі.

Крипто-схеми відмивання

Відмивання через криптовалюти

1
Розміщення (Placement)
Купівля BTC/ETH через P2P-платформи або нерегульовані обмінники
2
Змішування (Mixing)
Tumbler/mixer змішує монети тисяч користувачів, розриваючи ланцюжок
3
Стрибки між ланцюжками (Chain Hopping)
BTC → Monero → ETH → stablecoin: перехід між блокчейнами через DEX
4
Виведення (Cash Out)
Виведення через регульовану біржу з підробленим KYC або через OTC-desk

Аналітика блокчейну (Blockchain Analytics) — Chainalysis, Elliptic — відстежує до 95% транзакцій, навіть після змішування.

Мережі компаній-оболонок (Shell Companies)

Фіктивні корпоративні структури

🕸️
Структура мережі
Офшорні юрисдикції (BVI, Panama)
Номінальні директори та акціонери
Багатошарові ланцюжки володіння
Реальний бенефіціар (UBO) прихований за 5+ рівнями
🔍
Методи виявлення
Реєстри бенефіціарів (UBO)
Графовий аналіз зв'язків
Panama/Pandora Papers
Спільні адреси, директори, аудитори

«Тройка Ландромат» — $8.8 млрд відмито через 70+ shell companies з однією адресою в Естонії.

Індикатори підозрілості (Red Flags)

Ознаки можливого відмивання

🚩 Невідповідність профілю: студент з оборотом $500K/місяць
🚩 Циклічний рух коштів (Round-Tripping): кошти повертаються до відправника через ланцюжок посередників
🚩 Швидке переміщення (Rapid Movement): кошти переказуються протягом хвилин після надходження
🚩 Високоризикові країни: транзакції з юрисдикціями сірого/чорного списку без бізнес-обгрунтування
🚩 Готівкоємний бізнес (Cash-Intensive): надмірний обсяг готівкових операцій без логічного пояснення
🚩 Структурування: систематичні операції трохи нижче порогу обов'язкового звітування
🛡️

Ключові висновки

1️⃣ 3 етапи — розміщення → розшарування → інтеграція
2️⃣ Крипто-відмивання — міксери, стрибки між ланцюжками ускладнюють відстеження
3️⃣ Грошові мули (Money Mules) — жертви рекрутингу стають співучасниками
4️⃣ Структурування — дроблення нижче порогу = окремий злочин
