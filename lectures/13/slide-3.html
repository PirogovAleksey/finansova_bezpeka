Безпека кінцевих точок (Endpoint Security)

🔄
Оновлення
Автооновлення ОС та додатків. 60% атак через відомі, але невиправлені вразливості
🛡️
Антивірус / EDR
Windows Defender — базово. CrowdStrike, SentinelOne — корпоративно
🔐
Шифрування диска (Disk Encryption)
BitLocker / FileVault / LUKS. Крадіжка пристрою ≠ крадіжка даних
🔒
Блокування екрана (Screen Lock)
Автоблокування 1-5 хв, PIN/біометрія. Не залишайте розблокованим

Безпека мережі

📶Домашній Wi-Fi — WPA3, складний пароль, зміна облікових даних адміністратора роутера
☕Публічний Wi-Fi — НІКОЛИ фінансові операції без VPN. MITM тривіальний
🔒VPN — WireGuard для особистого, корпоративний VPN для роботи
🏠IoT — розумні пристрої в окрему мережу (гостьова мережа), оновлення прошивки

Чек-лист захисту ОС (Hardening)

🔄Автооновлення — увімкніть автоматичне оновлення для ОС, браузера та всіх додатків
🛡️Брандмауер (Firewall) — увімкніть вбудований брандмауер (Windows Defender Firewall / macOS Firewall)
👤Права доступу — працюйте з обмеженим акаунтом, admin лише для інсталяцій
🔐BitLocker / FileVault — увімкніть повне шифрування диска
🚫Непотрібні сервіси — вимкніть Remote Desktop, SMBv1, Telnet якщо не використовуєте
📋AppLocker / Gatekeeper — дозволяйте лише підписані додатки з відомих джерел

Безпека домашнього роутера

🔑
Зміна паролів
Admin: admin/admin — перше що перевіряє зловмисник. Змініть негайно!
📶
WPA3 / WPA2-AES
Вимкніть WEP та WPS. Пароль Wi-Fi мінімум 16 символів
🔄
Оновлення прошивки (Firmware Update)
Перевіряйте оновлення щомісяця. Роутери рідко оновлюються автоматично
🌐
DNS фільтрація
Встановіть DNS: Quad9 (9.9.9.9) або Cloudflare (1.1.1.2) для блокування шкідливих сайтів

Зламаний роутер = зловмисник бачить ВСЕ: паролі, банкінг, листування. Це найважливіший пристрій у мережі.

Порівняння VPN-протоколів

⚡
WireGuard
Сучасний, швидкий, ~4000 рядків коду. Найкращий вибір для особистого VPN
🔒
OpenVPN
Перевірений часом, гнучкий, працює через TCP/443 (обхід блокувань)
🏢
IPsec / IKEv2
Корпоративний стандарт, стабільний при зміні мережі (мобільні пристрої)
🚫
PPTP
Застарілий, зламаний. НІКОЛИ не використовуйте — еквівалент відсутності шифрування

Безкоштовні VPN часто збирають та продають ваші дані. Краще власний VPN на VPS або платний провайдер з аудитом (Mullvad, ProtonVPN).

Безпека IoT-пристроїв

📶Окрема мережа — створіть Guest Wi-Fi для IoT. Ізоляція від основних пристроїв
🔑Паролі за замовчуванням — змініть на кожному пристрої. Ботнет Mirai зламав 600K пристроїв через стандартні облікові дані
🔄Прошивка (Firmware) — оновлюйте камери, розетки, термостати. Обирайте виробників з підтримкою оновлень
🚫UPnP — вимкніть на роутері. Автоматичне відкриття портів = загроза безпеці

Зламана IP-камера або розумна колонка = шпигунство у вашому домі. Перед покупкою IoT перевірте репутацію виробника.

🛡️

Ключові висновки

1️⃣Оновлення — #1 захист: автооновлення закриває 60% відомих вразливостей
2️⃣Повне шифрування диска (Full Disk Encryption) — BitLocker/FileVault на кожному пристрої
3️⃣Публічний Wi-Fi — тільки з VPN, ніколи фінансові операції без захисту
4️⃣IoT — окрема мережа для розумних пристроїв
