Виявлення аномалій (Anomaly Detection)

📊
З учителем (Supervised)
Random Forest, XGBoost, NN. Навчання на розмічених даних
🔍
Без учителя (Unsupervised)
Isolation Forest, Autoencoders. Без міток, виявлення відхилень
🔄
Напівкероване (Semi-supervised)
Модель «нормального». Все інше = аномалія
⚡
Глибоке навчання (Deep Learning)
LSTM, Transformer для аналізу послідовностей у часових рядах

Аналітика поведінки (UEBA)

User and Entity Behavior Analytics

1
Базовий профіль
Час входу, ресурси, обсяг даних, геолокація
2
Моніторинг
Кожна дія порівнюється з базовим профілем
3
Оцінка ризику
Відхилення збільшує динамічний показник ризику
4
Сповіщення
Високий показник → сповіщення SOC-аналітику з контекстом

Внутрішня загроза (insider threat): працівник банку о 2 AM скачує базу клієнтів, яку ніколи не використовував. UEBA це бачить.

SOAR: автоматизоване реагування

Security Orchestration, Automation and Response

1
Виявлення (Detection)
AI визначає рівень загрози та класифікує інцидент
2
Ізоляція (Isolation)
Автоматичне відключення скомпрометованого endpoint від мережі
3
Блокування (Blocking)
Блокування шкідливих IP на firewall, відкликання сесій
4
Ескалація (Escalation)
Тікет в ITSM, сповіщення SOC-команди з повним контекстом

Платформи: Palo Alto XSOAR, IBM QRadar SOAR, Splunk SOAR. MTTR скорочується з годин до хвилин.

Порівняння ML-алгоритмів для безпеки

🌲
Random Forest
Точність 92-95%, швидке передбачення, інтерпретабельний. Найкращий для табличних даних
⚡
XGBoost / LightGBM
Точність 95-97%, градієнтний бустинг. Лідер Kaggle-змагань з виявлення шахрайства
🧠
Глибоке навчання (LSTM)
Точність 93-96% для послідовностей. Ідеальний для часових рядів та мережевого трафіку
🔮
Isolation Forest
Без учителя, не потребує міток. Виявляє нові типи атак без попереднього навчання

На практиці найкращий результат дає ensemble: XGBoost для відомих патернів + Isolation Forest для zero-day.

Архітектура UEBA-системи

1
Збір даних
AD logs, VPN, email, файлові сервери, endpoint → Data Lake
2
Витяг ознак (Feature Extraction)
Час, частота, обсяг, ресурси, група колег → вектор ознак
3
ML-рушій
Autoencoder будує базовий профіль, відхилення = оцінка аномалії (0-100)
4
Агрегація ризиків (Risk Aggregation)
Множинні аномалії з різних джерел → єдиний показник ризику сутності
5
Реагування
SOAR-інтеграція: автоматичне блокування, ізоляція, ескалація до SOC

Витік даних (аномальне вивантаження)

Перебір паролів та розпилення паролів (password spray)

Автоматизований конвеєр пошуку загроз (Threat Hunting Pipeline)

1
Збір даних
SIEM + EDR + NDR + Cloud logs → єдиний data lake для аналізу
2
AI-гіпотези
ML-модель генерує гіпотези: «можливий lateral movement на сервер X»
3
Автоматична верифікація
AI перевіряє гіпотезу через додаткові запити до логів, endpoint-дані
4
Збагачення контексту
Розвідка загроз (Threat Intelligence), MITRE ATT&CK mapping, оцінка ризику автоматично
5
SOC Playbook
Аналітик отримує готовий кейс з контекстом, IoC та рекомендаціями дій

Ключові висновки

1️⃣ AI — виявляє zero-day та невідомі загрози через поведінковий аналіз
2️⃣ UEBA — базовий профіль + оцінка ризику для внутрішніх загроз та скомпрометованих акаунтів
3️⃣ NDR — ML для аналізу мережевого трафіку, виявлення C2 та ексфільтрації (exfiltration)
