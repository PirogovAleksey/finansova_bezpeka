Порівняння ML-підходів для безпеки

🌲
Supervised: XGBoost, Random Forest
Точність 95-97% на табличних даних. Лідер fraud detection. SHAP для інтерпретації рішень
🔮
Unsupervised: Isolation Forest
Без учителя, без міток. Ізолює аномалії через випадкові розбиття. Zero-day детекція
♻️
Semi-sup: Autoencoders, VAE
Реконструкція нормальних даних, помилка відновлення = аномалія. Основа UEBA
🔄
Deep Learning: Transformers
Self-attention на послідовностях подій. APT detection, аналіз логів. LSTM — legacy
🕸️
Graph Neural Networks (GNN)
Граф рахунків і зв'язків. AML, lateral movement, виявлення шахрайських мереж
🤖
LLM / Foundation Models
Security Copilot, Gemini in Chronicle. Пріоритизація алертів (triage), KQL-запити, SIGMA-правила

Сучасний SOC-стек комбінує XGBoost для відомих патернів, Isolation Forest для zero-day, GNN для мережевих атак і LLM-copilot для triage.

Глибоке навчання у кібербезпеці (Deep Learning)

🔄
Transformers
Self-attention на послідовностях подій. Виявляють APT-атаки через аналіз тижневих ланцюжків. Основа Google Chronicle, Microsoft Security Copilot, IBM watsonx
🖼️
CNN
Класифікація шкідливого ПЗ через візуалізацію бінарних файлів як зображень. Точність 98%+ (Microsoft Malware Challenge). Стійкість до обфускації коду
📼
LSTM / GRU (застарілі)
Рекурентні архітектури для часових рядів. Витіснені трансформерами; зустрічаються у спадкових системах з обмеженими обчислювальними ресурсами

У 2025-2026 Transformers домінують для аналізу логів, детекції APT та SOC-асистентів. DL потребує великих обсягів даних та GPU — обмеження для менших фінансових установ.

Аналітика поведінки (UEBA)

User and Entity Behavior Analytics

1
Базовий профіль
Час входу, ресурси, обсяг даних, геолокація
2
Моніторинг
Кожна дія порівнюється з базовим профілем
3
Оцінка ризику
Відхилення збільшує динамічний показник ризику
4
Сповіщення
Високий показник → сповіщення SOC-аналітику з контекстом

Внутрішня загроза (insider threat): працівник банку о 2 AM скачує базу клієнтів, яку ніколи не використовував. UEBA це бачить.

Архітектура UEBA-системи

1
Збір даних
AD logs, VPN, email, файлові сервери, endpoint → Data Lake
2
Витяг ознак (Feature Extraction)
Час, частота, обсяг, ресурси, група колег → вектор ознак
3
ML-рушій
Autoencoder будує базовий профіль, відхилення = оцінка аномалії (0-100)
4
Агрегація ризиків (Risk Aggregation)
Множинні аномалії з різних джерел → єдиний показник ризику сутності
5
Реагування
SOAR-інтеграція: автоматичне блокування, ізоляція, ескалація до SOC

Аналіз мережевого трафіку (NDR)

>70%
мережевого трафіку зашифровано (TLS 1.3, QUIC) — і частка зростає
99%+
точність виявлення malware у зашифрованому трафіку за метаданими (Cisco ETA)
🔐 Аналіз метаданих без дешифрування — розмір пакетів, інтервали, ентропія payload, JA3/JA3S-фінгерпринти TLS-з'єднань
📡 C2-маячки (beaconing) — регулярні «пульси» зв'язку з командним сервером, нетипові розміри пакетів
🌐 DNS Tunneling — висока ентропія DNS-запитів, незвично довгі піддомени
🛡️ Платформи NDR — Darktrace, Vectra AI, ExtraHop: автоматичне виявлення та реагування

AI генерує гіпотези про загрози з логів, трафіку та endpoint-телеметрії. Втома від сповіщень (alert fatigue) — ключова проблема SOC.

Автоматизований конвеєр пошуку загроз (Threat Hunting Pipeline)

1
Збір даних
SIEM + EDR + NDR + Cloud logs → єдиний data lake для аналізу
2
AI-гіпотези
ML-модель генерує гіпотези: «можливий lateral movement на сервер X»
3
Автоматична верифікація
AI перевіряє гіпотезу через додаткові запити до логів, endpoint-дані
4
Збагачення + MITRE ATT&CK
Розвідка загроз (Threat Intelligence), мапінг техніки на MITRE ATT&CK, оцінка ризику
5
SIGMA-правило + SOC Playbook
Формалізація знахідки у SIGMA (3000+ правил SigmaHQ), аналітик отримує кейс з IoC та рекомендаціями

SOAR: 5 етапів автоматизованого реагування

Security Orchestration, Automation and Response

1
Детекція (Detection)
SIEM/NDR генерує алерт: підозрілий вихідний трафік, невдалі спроби входу
2
Збагачення (Enrichment)
Запит контексту з VirusTotal, AlienVault OTX, MISP: репутація IP, зв'язки з APT
3
Рішення (Decision)
AI обчислює risk score: auto-response при >85 або ескалація аналітику
4
Дія (Action)
Ізоляція endpoint, блокування IP на firewall, відкликання сесій, ITSM-тікет
5
Документування (Documentation)
Автоматичний звіт з timeline, зібраними артефактами, вжитими заходами

Платформи: Palo Alto XSOAR, IBM QRadar SOAR, Splunk SOAR. Playbooks для різних інцидентів (фішинг, витік даних, ransomware). MTTR скорочується з годин до хвилин (Palo Alto Networks, 2025).
