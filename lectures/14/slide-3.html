Що таке SOC?

Центр безпекових операцій (Security Operations Center, SOC) — централізований підрозділ для безперервного моніторингу, виявлення та реагування на кіберзагрози. Для великих фінансових установ — 24/7/365.

Рівні аналітиків SOC

T1
Сортування алертів (Triage)
Моніторинг алертів, класифікація, ескалація. Робочі інструкції
T2
Аналіз інцидентів
Глибокий аналіз, кореляція даних, масштаб та вплив
T3
Полювання на загрози (Hunting)
Проактивний пошук загроз, аналіз шкідливого ПЗ, правила виявлення
MGR
Менеджер SOC
Координація, метрики, звітування, взаємодія з бізнесом

Ключові технології SOC

📊
SIEM
Збір та кореляція логів. Splunk, Microsoft Sentinel, Elastic SIEM
💻
EDR
Моніторинг endpoints. CrowdStrike, Defender for Endpoint, SentinelOne
⚡
SOAR
Автоматизація реагування. Palo Alto XSOAR, Splunk SOAR
🔍
Платформа розвідки загроз (TIP)
Threat Intelligence Platform. Агрегація IOC, збагачення алертів

SIEM — серце SOC

📥Збір логів — firewall, AD, endpoints, applications, cloud — усе в одному місці
🔗Кореляція — правила зв'язують події з різних джерел у єдину картину
🔔Алерти — автоматичне оповіщення аналітиків при спрацюванні правил
📈Інформаційні панелі (Dashboards) — візуалізація стану безпеки в реальному часі
🔎Криміналістичний пошук (Forensic Search) — ретроспективний пошук по збережених логах

Моделі SOC

🏢
Внутрішній SOC (In-house)
Повний контроль, глибоке знання бізнесу. Дорого: $2-5M/рік
🤝
Зовнішній (MSSP / MDR)
Аутсорсинг моніторингу. Дешевше, швидкий старт. Менше контролю
🔄
Гібридний SOC (Hybrid)
Критичні функції всередині, решта — MSSP. Оптимальний баланс

SIEM — приклади кореляційних правил

🔐Перебір паролів (Brute Force) — >10 невдалих логінів за 5 хв з однієї IP + успішний вхід = потенційна компрометація
📤Ексфільтрація даних (Data Exfiltration) — >500MB вихідного трафіку на зовнішню IP в неробочий час + DNS tunneling
👤Бокове переміщення (Lateral Movement) — один акаунт логіниться на >5 серверів за 10 хв + використання PsExec/WMI
⚠️Ескалація привілеїв (Privilege Escalation) — додавання користувача в Domain Admins + зміна GPO поза вікном змін
🌍Неможлива подорож (Impossible Travel) — логін з України та через 30 хв з Бразилії = компрометація облікового запису
Якість правил = баланс між detection rate та false positive rate. Тюнінг — постійний процес

EDR — можливості детектування

EDR (Endpoint Detection & Response) — агент на кожній кінцевій точці, що збирає телеметрію та реагує на загрози в реальному часі
🔍
Поведінковий аналіз
Виявлення безфайлового шкідливого ПЗ (fileless malware), атак типу living-off-the-land
🧬
Дерево процесів (Process Tree)
Повний ланцюжок: email → macro → cmd → powershell → C2
🔒
Автоізоляція
Автоматичне відключення зараженого хосту від мережі за мілісекунди
🔎
Полювання на загрози (Threat Hunting)
Ретроспективний пошук IOC по всіх кінцевих точках організації

SOAR — автоматизований сценарій реагування

SOAR (Security Orchestration, Automation & Response) — автоматизує рутинні задачі SOC та прискорює реагування
1
Тригер
SIEM алерт: phishing email з вкладенням detected
2
Збагачення
Автоперевірка URL у VirusTotal, sender у TI, хеш файлу
3
Аналіз
Sandbox detonation вкладення, перевірка хто ще отримав лист
4
Стримування
Видалити лист зі всіх скриньок, блокувати домен відправника
5
Документація
Автоматичне створення тікету, timeline, звіт для менеджера
⚡SOAR скорочує час реагування з годин до хвилин та вивільняє аналітиків для складних задач

Канали розвідки загроз (Threat Intelligence)

Розвідка загроз (Threat Intelligence) — інформація про загрози, що допомагає SOC діяти проактивно, а не лише реактивно
🔗
Тактичний рівень (IOC)
IP-адреси, домени, хеші шкідливого ПЗ. Автоматичний імпорт у SIEM для блокування
📊
Операційний рівень (TTP)
Тактики та процедури APT-груп. Використовують фреймворк MITRE ATT&CK
🌐
Стратегічний рівень
Геополітичні тренди, галузеві звіти. Для керівництва та стратегічного планування
📡Джерела: CERT-UA, FS-ISAC (фінансовий сектор), MISP, AlienVault OTX, комерційні фіди (Recorded Future, Mandiant)
🔄Інтеграція: STIX/TAXII протоколи для автоматичного обміну між організаціями
🛡️

Ключові висновки

1️⃣SOC = люди + процеси + технології — всі три компоненти критичні
2️⃣SIEM + EDR + SOAR — технологічний фундамент сучасного SOC
3️⃣Рівнева модель — T1 сортування → T2 аналіз → T3 полювання — ефективно розподіляє навантаження
4️⃣Гібридний SOC — оптимальний вибір для більшості фінансових установ
