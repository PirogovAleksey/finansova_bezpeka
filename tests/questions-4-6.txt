ТЕСТ 4: Клієнтські атаки (XSS)

1. Який тип XSS вважається найнебезпечнішим через те, що шкідливий код зберігається на сервері та виконується у браузері кожного відвідувача?
А) Reflected XSS
Б) DOM-based XSS
В) Stored XSS
Г) Self-XSS
Відповідь: В

2. Чому DOM-based XSS не може бути виявлений серверними WAF-системами?
А) Тому що WAF не підтримують JavaScript
Б) Тому що payload передається через fragment (#) і не надсилається на сервер
В) Тому що DOM-based XSS використовує шифрування
Г) Тому що WAF працюють лише з POST-запитами
Відповідь: Б

3. Яка атака змушує браузер автентифікованого користувача надіслати небажаний запит до вразливого сайту, використовуючи автоматичне додавання cookies?
А) XSS
Б) Clickjacking
В) CSRF
Г) Formjacking
Відповідь: В

4. Який атрибут cookie забороняє доступ до нього через JavaScript, захищаючи від крадіжки через XSS?
А) Secure
Б) SameSite
В) HttpOnly
Г) Path
Відповідь: В

5. Яке значення атрибуту SameSite рекомендується для фінансових систем як максимальний захист від CSRF?
А) None
Б) Lax
В) Permissive
Г) Strict
Відповідь: Г

6. Який HTTP-заголовок є сучасною заміною X-Frame-Options для захисту від клікджекінгу?
А) Content-Security-Policy: frame-ancestors
Б) Access-Control-Allow-Origin
В) X-Content-Type-Options
Г) Referrer-Policy
Відповідь: А

7. Що таке формджекінг (Formjacking)?
А) Атака на серверні форми автентифікації
Б) Ін'єкція шкідливого JavaScript у платіжні форми для крадіжки даних карток у реальному часі
В) Підробка HTML-форм через CSRF-токени
Г) Маніпуляція DOM-елементами форм для зміни валідації
Відповідь: Б

8. Яка група здійснила серію масштабних formjacking-атак на British Airways, Ticketmaster та Newegg?
А) Anonymous
Б) Lazarus Group
В) Magecart
Г) Fancy Bear
Відповідь: В

9. Який механізм захисту перевіряє криптографічний хеш зовнішнього скрипта, щоб запобігти виконанню зміненого файлу з CDN?
А) Content Security Policy (CSP)
Б) Subresource Integrity (SRI)
В) CORS (Cross-Origin Resource Sharing)
Г) HSTS (HTTP Strict Transport Security)
Відповідь: Б

10. Де рекомендується зберігати access token у фінансових веб-додатках для максимальної безпеки?
А) У localStorage
Б) У sessionStorage
В) У пам'яті (JavaScript-змінна)
Г) У cookie без атрибуту HttpOnly
Відповідь: В


ТЕСТ 5: Серверні вразливості та бази даних

1. Який тип SQL-ін'єкції дозволяє зловмиснику визначати відповідь (true/false) за різницею у поведінці сторінки, не отримуючи результат запиту безпосередньо?
А) Classic (In-band) SQLi
Б) UNION-based SQLi
В) Blind SQLi (Boolean-based)
Г) Out-of-band SQLi
Відповідь: В

2. Що таке SQL-ін'єкція другого порядку (Second-Order SQL Injection)?
А) Ін'єкція через два різні параметри одночасно
Б) Ін'єкція, де шкідливі дані спочатку зберігаються у базі, а спрацьовують при подальшому використанні в іншому запиті
В) Подвійна ін'єкція через UNION SELECT
Г) Ін'єкція через два вкладені SQL-запити
Відповідь: Б

3. Яка IP-адреса AWS metadata endpoint, доступ до якої через SSRF дає зловмиснику IAM credentials?
А) 192.168.1.1
Б) 10.0.0.1
В) 127.0.0.1
Г) 169.254.169.254
Відповідь: Г

4. Який інцидент 2019 року став знаковим прикладом SSRF-атаки з витоком даних 106 мільйонів клієнтів та штрафами у $80 мільйонів?
А) Equifax breach
Б) Capital One breach
В) Yahoo breach
Г) Marriott breach
Відповідь: Б

5. Який основний метод захисту від SQL-ін'єкцій вважається найнадійнішим?
А) Input validation
Б) WAF (Web Application Firewall)
В) Параметризовані запити (Prepared Statements)
Г) Шифрування SQL-запитів
Відповідь: В

6. Яка вразливість XML-парсерів дозволяє читати файли сервера через зовнішні сутності та є особливо актуальною для SWIFT-повідомлень та ISO 20022?
А) SSRF
Б) XXE (XML External Entity)
В) SSTI
Г) Command Injection
Відповідь: Б

7. Який механізм бази даних PostgreSQL обмежує доступ на рівні рядків, дозволяючи менеджеру бачити лише клієнтів свого відділення?
А) Column-level Encryption
Б) Dynamic Data Masking
В) Row-Level Security (RLS)
Г) Transparent Data Encryption (TDE)
Відповідь: В

8. Яке шифрування захищає файли бази даних на диску від крадіжки фізичних носіїв і вимагається PCI DSS для номерів карток?
А) Encryption in Transit
Б) Encryption at Rest (TDE)
В) Application-level Encryption
Г) Homomorphic Encryption
Відповідь: Б

9. Яка серверна вразливість виникає, коли дані користувача потрапляють у шаблонізатор (Jinja2, Twig) без обробки і може призвести до Remote Code Execution?
А) XXE
Б) SSRF
В) SSTI (Server-Side Template Injection)
Г) CSRF
Відповідь: В

10. Що означає принцип найменших привілеїв стосовно баз даних у фінансовій системі?
А) Кожен користувач має однаковий доступ до всіх таблиць
Б) Кожен мікросервіс має окремий обліковий запис бази з мінімально необхідними правами
В) Доступ до бази мають лише адміністратори
Г) Усі запити до бази проходять через один спільний обліковий запис
Відповідь: Б
